Análisis de aprendizaje por IA

Visto en clase Función Aprendido por la IA Función
color Define el color del texto :root / var() Crea variables reutilizables para colores, tamaños, etc.
background-color Define el color de fondo box-shadow Agrega sombra alrededor de un elemento
font-family Define el tipo de letra border-radius Redondea las esquinas de un elemento
font-size Define el tamaño de letra transition Suaviza el cambio entre dos estados (animación)
font-weight Define el grosor de la letra transform Escala, rota o mueve un elemento
font-style Define si el texto es cursiva/normal display: flex Alinea elementos en fila o columna fácilmente
text-align Alinea el texto (izq/centro/der) justify-content / align-items Distribuyen y alinean elementos dentro de un flex/grid
line-height Define el interlineado flex-wrap / gap Permite saltos de línea y da espacio entre elementos
text-decoration Subraya, tacha el texto display: grid Crea una cuadrícula de filas y columnas
text-transform Cambia mayúsculas/minúsculas grid-template-columns / repeat() / minmax() / auto-fit Define cuántas columnas tiene el grid y su tamaño flexible
margin Espacio afuera del elemento position: fixed / sticky / absolute / relative Controla cómo se posiciona un elemento en la página
width Define el ancho de un elemento z-index Controla qué elemento queda encima de otro
Selector universal (*) Aplica estilo a todos los elementos opacity Controla la transparencia de un elemento
Selector de etiqueta Aplica estilo a una etiqueta HTML específica backdrop-filter Difumina el fondo detrás de un elemento
Selector de clase (.clase) Aplica estilo a elementos con esa clase linear-gradient() Crea un degradado de colores
Selector de ID (#id) Aplica estilo a un solo elemento único @keyframes / animation Crea animaciones personalizadas paso a paso
Estilos embebidos (style="") Aplica estilo directo en la etiqueta HTML :hover / ::before / ::after Cambia el estilo al pasar el mouse / agrega contenido decorativo
Etiqueta <style> Define estilos dentro del head del HTML object-fit Controla cómo se ajusta una imagen dentro de su contenedor
Comentarios /* */ Explica el código sin afectar el resultado clamp() Define un valor que se adapta entre un mínimo y máximo
<link rel="stylesheet" href=""> Enlaza un archivo CSS externo @media (responsive) Aplica estilos distintos según el tamaño de pantalla
box-sizing: border-box Incluye el padding y borde dentro del ancho total scroll-behavior: smooth Hace que el scroll se mueva suavemente
filter Aplica efectos visuales (brillo, invertir colores, etc.) letter-spacing Controla el espacio entre letras
overflow / white-space Controla si el contenido se corta o se mantiene en una línea inset Define top/right/bottom/left en una sola propiedad
content (pseudo-elementos) Inserta contenido decorativo sin usar HTML JavaScript: addEventListener, classList.toggle Detecta eventos (clic, scroll) y cambia clases dinámicamente
